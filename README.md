## 🎨 Главный арт проекта

```text
          ______________________________________
         |  ERROR: почему оно опять не работает? |
         |_______________________________________|
                     /
        ( x _ x )   /
        /|  ☕  |\        "Я только цвет кнопки
         | _____ |          поменять хотел..."
        /|_______|\
          /     \
         /_______\

       .-------------------.
       |  console.log("😭") |
       '-------------------'
                 \
                  \   🦆
                    /\
             "А ты пробовал
              перезапустить?"
```

## 🤔 Что это?

Это высокотехнологичная система, созданная на стыке инноваций, кофеина и фразы «да вроде всё понятно».

Проект умеет:
- решать задачи, которых вчера не существовало;
- превращать одну ошибку в целую экосистему ошибок;
- работать идеально — пока на него кто-нибудь не посмотрит;
- заставлять автора гуглить собственный код.

## 🛠️ Технологический стек

- **TypeScript** — чтобы страдать ещё до запуска.
- **React** — чтобы рендерить проблемы декларативно.
- **CSS** — чтобы кнопка была на 2 пикселя левее, чем нужно.
- **Git** — чтобы сохранять историю своих ошибок.
- **Stack Overflow** — коллективный разум проекта.
- **Кофе** — runtime dependency.

## 🚀 Запуск

```bash
git clone <repository-url>
cd <project-folder>
yarn install
yarn dev
```

Если не работает:

1. Проверьте, установлен ли Node.js.
2. Проверьте, запустили ли вы правильную команду.
3. Посмотрите в консоль.
4. Скажите «странно, у меня работало».
5. Перезапустите терминал, редактор, компьютер и жизненные решения.

## 🐛 Известные особенности

- Иногда приложение работает.
- Иногда приложение думает.
- Иногда приложение выбирает свободу и закрывается.
- `TODO: fix later` — важнейшая часть архитектуры.
- Не удаляйте `console.log`: возможно, это единственное, что удерживает проект от распада.

## 📊 Метрики качества

| Показатель | Значение |

# Билли Херрингтон

**Билли Херрингтон** (Billy Herrington) — американский культурист, актёр и интернет-мем, получивший широкую известность в русскоязычном сегменте интернета благодаря видео с его участием и последующим мемам.

## Биография

Билли Херрингтон родился 14 июля 1969 года в Норт-Бэбилон, штат Нью-Йорк. В молодости занимался борьбой, затем увлёкся бодибилдингом. В 1990-х годах начал сниматься в качестве модели и актёра.

В 1998 году получил известность как актёр в фильмах для взрослых, после чего стал популярной фигурой в ЛГБТ-сообществе и поп-культуре.

Скончался 2 марта 2018 года в результате автомобильной аварии в Риверсайде, Калифорния.

## Интернет-мем

В русскоязычном сегменте интернета (и не только) Билли Херрингтон стал героем множества мемов, связанных с:

- Фразой **«Ah, fuck you»** и другими репликами из его видео;
- Видеорядом **«Gachi»** — нарезками из его фильмов;
- Музыкальными пародиями (**«Gachi Gang»**, ремиксы);
- Персонажем **«Билли-сан»** в аниме-сообществе.

Мемы с Билли Херрингтоном часто используются в качестве шуточных реакций, музыкальных нарезок и пародий.
